# Translation maintenance

English README.md is the reference text. French, Dutch and Vietnamese versions are in docs/translations/. All four retain the same section identifiers and executable PowerShell blocks. Each translated file links back to ../../README.md and to sibling translations.

Translate descriptions and headings, not commands, filenames, band identifiers, configuration keys or numeric values. Preserve qualifiers and scope: a functional check must not become scientific validation in translation. Shared figures, if added, must remain descriptive diagrams without research results. Review translated prose alongside every substantive English change.

The documentation check detects missing files, broken local targets, anchor problems, changed executable blocks and missing/reordered section identifiers. It does not evaluate linguistic accuracy. A synchronized version label identifies the intended reference release; it is not independent certification. Translation fixes may be proposed through pull requests. Technical supporting pages currently remain in English.
