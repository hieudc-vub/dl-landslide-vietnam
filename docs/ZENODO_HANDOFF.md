# Dataset publication and file layout

The dataset is published at https://doi.org/10.5281/zenodo.23838723, version 1.0.0, under CC BY-NC 4.0 within the owner's rights. The owner distributes three raster ZIP archives on Zenodo and keeps schema, pair/raster manifests, citation and reuse documentation in GitHub. No metadata ZIP is distributed on Zenodo.

See [download and verification instructions](DATASET_RELEASE.md). The dataset DOI is not a software DOI or article DOI. Preserve the existing source release and dataset archives; record documentation changes in Git history. A future dataset version may have a different version-specific DOI.

The initial Zenodo checksum/script pair expected a fourth metadata archive. The separate correction files supplied to the owner change verification to the approved three-archive layout; raster archive hashes remain unchanged. Until those two Zenodo files are corrected, use the three-entry checksums and verifier from this GitHub snapshot.
